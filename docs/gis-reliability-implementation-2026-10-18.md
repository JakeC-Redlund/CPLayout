- KML map-feature IDs are reserved once across all selected point, line and polygon candidates against the existing durable IDs. Source IDs retained in properties do not substitute for unique durable identity. Editing one imported sibling cannot inadvertently edit another feature that shared its source ID.

Focused regressions cover changed boundaries with equal and different vertex counts, unchanged provenance, unsupported geometry, input immutability, selected-one/selected-all imports, preexisting ID collisions, cancellation, undo/redo, and lossless project-document reopen.
