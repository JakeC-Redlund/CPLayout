# CPLayout Agent Source Ledger

This ledger records sources used to define the agent, hook, and skill surfaces. Use primary or official sources for claims that affect architecture, platform behavior, database behavior, Google Earth/KML evidence, or real-world irrigation design.

Freshness metadata uses:

- `freshness=current`: checked on the listed date and suitable for bounded process guidance until a relevant Codex/package/platform change is suspected.
- `freshness=refresh-required`: source-backed claim should be refreshed before package/platform architecture, managed policy, or runtime-proof changes.
- `freshness=artifact-specific`: report-backed claim applies only to the named artifact, schema, build, device, and completed report.

Checked dates record when the source or report was reviewed, not a permanent runtime guarantee. Package/platform claims must be refreshed before architecture changes, and report-backed native or Google Earth claims apply only to the named proof artifact and checklist scope.
