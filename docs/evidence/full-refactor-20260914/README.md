These records preserve bounded observations from the active refactor, not a completed release or field-accuracy claim.

- `field-plan-reuse.json` derives nine complete-output comparisons and operation counts from retained before/after bundles. The post-review signed-zero counts agree. Shared-host timings are omitted from this curated summary because they do not establish a speedup. The registered regression suite preserves output digests, yield counts and strict signed-zero checks.
- `optimizer-reuse.json` verifies strict input/result equality for 20 retained V8 snapshots, including signed zero. Instrumented counts are retained separately from coordinator/reviewer parity checks; they were not independently re-instrumented. This later source is not included in the `WgcDsc` browser results.
- `advisory-readiness.json` records nine selected `WgcDsc` browser passes across desktop, tablet and phone with zero retries or skips. It does not represent the complete inventory or later application changes.

Later aggregate validation exposed a standalone-clearance compatibility regression omitted by that focused set; the correction needs separate source-bound acceptance. These results do not establish solver convergence, physical scale or field accuracy.
- `import-save-ownership.json` preserves nine probes of the actual App functions with stubbed callbacks. Save ordering and generation acknowledgements passed; React/browser/storage execution requires the separate browser run.
- `native-single-process.json` retains the failed collector outcome, observed current-process SQLite/in-memory ZIP facts, artifact identities and cleanup. OS file selection, restart/upgrade, consumed bundle identity, native MapLibre, hardware and 3D accuracy remain unverified.

Selected browser success does not make that candidate accepted. This snapshot predates the standalone-clearance correction and the draft archive packet.
