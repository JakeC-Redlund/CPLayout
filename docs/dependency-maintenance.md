# Recurring dependency maintenance

The checked-in automation consists of weekly Dependabot npm and GitHub Actions update groups and a daily dependency report workflow. It is source configuration until hosted runs and update PRs are observed. No scheduled job deploys the application or merges a PR unconditionally.

The daily job installs the exact lock, verifies the installed security patches, retains raw audit/outdated results, checks Expo compatibility and runs the existing strict audit admission. Reports expose unavailable registry/process errors rather than convert them into zero findings. The package installation runs reviewed postinstall guards; passing fixture tests alone does not establish installed mitigation.

Weekly npm groups keep Expo/React/native peers coherent and isolate geometry/storage/compiler/browser families. Ordinary version updates stay within majors and exclude prereleases. Vulnerability-driven security PRs are separate from the weekly version schedule and depend on repository security-update enablement. That hosted setting remains unverified until explicitly inspected. Security findings requiring a major are reported for a delegated migration decision rather than silently ignored as resolved.

A coordinator merges a bot PR only after independent source-bound compatibility review, a reviewed exact head, passing protected `cplayout-required`, installed mitigation verification and applicable runtime proof. Native changes require current device/native evidence before qualification. SDK/toolchain majors, zero-major breaking changes, golden geometry drift or modified patch provenance require their own bounded migration packet. Use an ordinary exact-head merge; no force push, branch-protection bypass or assumed human acceptance.

The daily npm report and weekly npm/action update proposals include the current workspace's backend packages, including the PostgreSQL client and authentication/service dependencies. Node and the PostgreSQL service image have separate platform pins: recheck supported stable releases and exact primary-source artifacts before changing either pin, then run the affected compatibility/database/source checks. The current [CI source record](evidence/production-workflow-dependencies-20261011/ci-primary-sources.json) verifies the official PostgreSQL 18.6 tag/digest and exact action manifests; it does not prove a container or hosted job ran. Keep the image digest under review as part of this maintenance process. This configuration does not claim Dependabot automatically updates Docker service-image references or performs database upgrades.
