# ***CPLAYOUT CONCEPTUAL DESIGN PREFERENCES***

The following information provided in this file is intended to provide agents and developers a detailed understanding of the concepts and ideas intended to be incorporated in the final product developed.



## **INTERFACE PREFERENCES**



### Splash/Login Screens



#### *Splash screens and loading window*



* The initial screen displayed prior to any login screen should be utilized to provide information to the user regarding the initialization process, as well as brand recognition and version information for the software interface.
* A short animation for visual effect to provide resulting brand recognition to the software
* DaVinci Resolve skills coordinated and combined with image generation capabilities should be utilized to develop videos for producing resulting splash animations.

  * Utilize computer vision to review any developed visual effects to ensure cutting-edge capabilities result in desired high-quality video splash animations



##### *Login Screen*



The login screen should provide branded and stylized interface allowing front-end operation for use with backend user database tables. The concept is to provide a username and password for identification and determination of access levels for the user login information provided.
Database must be maintained for users, administrators, and development team. Preferred database is to utilize PostgreSQL for open source development.
